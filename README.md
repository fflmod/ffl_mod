# FFLmod

『ファイナルファンタジー レジェンズ 光と闇の戦士』（Android版）向けの非公式modです。\
コントローラー・キーボードで遊べるようにし、遊びやすさを改善しています。

Unofficial mod for the Japanese Android version of *Final Fantasy Dimensions*
(FINAL FANTASY LEGENDS: Warriors of Light and Darkness, 1.2.0).

## 対象

- Google Playで購入した「FFレジェンズ 光と闇の戦士」1.2.0（arm64端末）
- Android専用です。iOS版には対応していません
- 英語版の*Final Fantasy Dimensions*（1.1.9）は別のアプリなので対象外です
- ゲーム本体のAPK・データは含まれていません。利用者が自分の端末にある正規版に差分を当てて使います
- ゲーム本体のコードは書き換えず、追加したコードから動作を変えています
- 正規版以外での動作は一切保証しません

## 主な機能

### 操作
- コントローラー・キーボードに対応。タッチ前提の画面は、汎用カーソルで選んで決定できます
- フィールドのダッシュ（ON/OFFボタン付き）
- ワイドスクリーン対応

### ジョブ・仲間
- 専用ジョブの統合：光・闇専用のジョブを両陣営で使える。転職可能なジョブは各キャラ最大12→17に
- すっぴんの強化：マスターしたジョブの能力値と、一部のパッシブアビリティ（反撃・警戒など）を引き継ぐ（FF5スタイル）
- 終章での仲間ゲストの再加入。同時に性能の強化も行っています
- 旧フリーシナリオにおける召喚獣の共有。終章以前から闇でラムウ、シヴァなどを使用可能
- メモリーズの使用枠調整
- ガウェインの装備がナイト編から変更可能に
- 隠しキャラの追加。終章で合流後に加入しています

### 戦闘
- 獲得経験値・ギル・APを1.5倍に
- レベルアップしたメンバーは戦闘後に全回復
- 敵の物理技（きりつけるなど）にもたたかうと同様に反撃し、混乱・睡眠の解除が働く
- スロウの強化。吟遊詩人編以降に設定されている耐性を貫通、単体／全体の選択、効果時間の延長
- 一部のモンスター及びボスモンスターの強さの調整
- アラームの追加。道具屋で100ギル。フィールドで使うと出現率の低いモンスターを呼び寄せる

### チャレンジダンジョン
- スマホ版で削除された暁の章～忍者編のチャレンジダンジョンを復活
- 各町のモーグリに、その場所を最初に訪れたときから挑戦可能
- 途中やボス戦後のレアアイテムを取りやすく調整
- 一部のダンジョンの仕掛けを遊びやすく調整
- マップの欠け・魔法陣の位置などの見た目の修正

ガラケー版と違い、各編のクリア後にゲストを伴って挑戦することはできません。\
ゲストと一緒に攻略したい場合は各編のクリア前に挑戦してください。\
特に暁の章のチャレンジダンジョンには竜騎士編開始以降、\
ナイト編のチャレンジダンジョンには忍者編開始以降、\
忍者編のチャレンジダンジョンには黄昏の章開始以降は挑戦できないので注意してください。

### その他
- 妖精の森の商人の宝箱の中身を調整
- 終章のファブリカの武器屋で夢の竪琴を買えるように
- mod向けのセーブの書き出し・取り込み機能。\
  正規版のクラウドセーブとGoogle データ エクスポートを利用して、PC不要で正規版のセーブデータを取り込めます

## 導入のしかた

### 1. 正規版のセーブをクラウドに保存する
- 正規版のゲームを起動し、タイトル画面の右上の雲のボタンを押す
- 「クラウドにセーブ」→「はい」と押す
- 「現在のデータとクラウドサーバーのデータが同一です。」と出れば完了

### 2. 管理アプリを入れる
- [Releases](https://github.com/fflmod/ffl_mod/releases)の最新版から`fflmod-manager.apk`をダウンロードする
- 「有害なファイルの可能性があります」と出たら、「ダウンロードを続行」を押す
- ダウンロードしたファイルを開き、「インストール」を押す
- Google Play プロテクトに「有害なアプリをブロックしました」と出たら、「OK」は押さずに「詳細」を開き、「インストールする」を押す

### 3. modを導入する
- 管理アプリ（FFレジェンズ mod導入アプリ）を開き、「modを導入」を押す
- 「正規版を削除します」→「続ける」、「セーブデータは保存しましたか？」→「削除する」、アンインストールの確認で「OK」と進む
- 「不明なアプリのインストール」の画面が出たら、「この提供元のアプリを許可」をオンにして戻る
- 「FF DIMENSIONS このアプリをインストールしますか？」と出たら「インストール」を押す
- 「modを導入しました。」と出れば完了

### 4. セーブを取り込む
- [Google データ エクスポート](https://takeout.google.com/)を開き、「選択をすべて解除」を押す
- 「Google Play Games サービス」だけにチェックを入れ、「次のステップ」を押す
- エクスポート先を「Google ドライブに追加」、頻度を「1 回のエクスポート」、ファイル形式を「.zip」にして、エクスポートを作成する
- 「完了」になったら、管理アプリで「セーブを取り込む」を押す
- ドライブの「Takeout」フォルダにある、新しいzipを選ぶ。zipは2つできるが、どちらを選んでも案内が出る
- 「取り込む」を押す。次にゲームを起動したときに反映される

## modの更新

管理アプリを開くと、現在のバージョンと最新バージョンが表示されます。\
アップデートがあるときは「modを更新」を押してください。セーブはそのまま残ります。

## セーブのバックアップ

管理アプリの「セーブを書き出す」で、セーブをファイルに保存できます。

## 正規版に戻すとき

mod版をアンインストールし、Google Playから正規版を入れ直してください。\
mod版のセーブは正規版にない仕組みのデータが入るため、正規版では使えません。\
正規版は、クラウドに保存したセーブから続けられます。
